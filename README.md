## 🚀 Featured Projects

### [Adversarial Beta Domain Randomization](https://github.com/FrancescoVanella/mldl_rl_project_25) — Robust Sim2Sim RL
Proposed **AdvBeta**, a novel adaptive domain randomization method that reshapes the parameter sampling distribution toward failure-inducing regions via a percentile-based curriculum.
- **+16.8%** target-domain return over Uniform Domain Randomization, with **~50%** lower inter-seed variance
- Implemented & compared REINFORCE, Actor–Critic, and Soft Actor–Critic on the MuJoCo Hopper benchmark using **PyTorch** and **Stable-Baselines3**

### [Salience-Guided Prompt Compression with SigExt](https://github.com/FrancescoVanella/dnlp_project) — Efficient LLM Summarization
SigExt-based strategies to compress prompts and select source documents for abstractive summarization.
- Phrase-level compression cut input tokens by **>70%** while preserving ROUGE & BERTScore
- Document-level selection reduced multi-document prompts by **~28%** at near-baseline quality
- Benchmarked GPT-3.5-Turbo, Mistral-7B-Instruct (4-bit), and Llama-3.1-8B

### [Predicting Real Estate Prices](https://github.com/FrancescoVanella/DSL_S25) 
End-to-end regression pipeline predicting U.S. rental prices from structured & unstructured features,  optimizing **XGBoost** and **Random Forest** models.
